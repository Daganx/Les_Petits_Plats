# Application Les Petits Plats

**Les Petits Plats** est une application web qui permet aux utilisateurs de découvrir des recettes de cuisine, d'explorer des ingrédients et de filtrer des plats en fonction de leurs préférences. Ce projet est réalisé dans le cadre du parcours de développeur d'applications front-end chez OpenClassrooms. L'objectif est de mettre en pratique les concepts de **React** et d'implémenter une interface utilisateur interactive et dynamique.

## Aperçu

**Les Petits Plats** est une plateforme où les utilisateurs peuvent explorer une variété de recettes, filtrer les résultats par ingrédients ou catégories, et voir les étapes de préparation. L'application vise à rendre la cuisine accessible et inspirante pour tous.

## Fonctionnalités

- **Recherche de recettes** : Les utilisateurs peuvent rechercher des recettes en fonction de différents critères (ingrédients, types de plats, etc.).
- **Affichage des détails des recettes** : Chaque recette inclut des informations sur les ingrédients, les étapes de préparation et des conseils de cuisine.
- **Filtrage dynamique** : Permet aux utilisateurs de filtrer les recettes en temps réel en fonction de leurs préférences.
- **Responsive Design** : Conçue pour être accessible sur mobiles, tablettes et ordinateurs.
- **Page d'accueil** : Présentation de recettes populaires et mise en avant de nouvelles recettes.

## Technologies Utilisées

- **React** : Pour la création de l’interface utilisateur.
- **React Router** : Pour la navigation entre les pages.
- **CSS Modules** : Pour un style localisé et éviter les conflits de classes.
- **API REST** : Pour récupérer les données des recettes depuis une API externe.

## Installation et Lancement du Projet

### Prérequis

- **Node.js** (version 16 ou supérieure)
- **npm** ou **yarn**

### Installation

1. **Cloner le dépôt**

   ```bash
   git clone https://github.com/daganx/les-petits-plats.git
   cd les-petits-plats
   ```

2. **Installer les dépendances**

    ```bash
    npm install 
    # ou 
    yarn install 
    ```

3. **Lancer le projet en mode développement**

    ```bash
    npm run dev
    # ou 
    yarn dev
    ```
